# Customer Segmentation System

A Python-based machine learning project that groups customers into
segments based on patterns in the customer dataset. The project uses
clustering to explore customer similarities and produces visualizations
and CSV files that help interpret the resulting groups.

## Project Objectives

-   Explore and prepare customer data for analysis.
-   Apply K-Means clustering to group similar customers.
-   Use the Elbow Method to help choose a suitable number of clusters.
-   Visualize the resulting customer segments.
-   Export segmented customer records and cluster summaries for further
    analysis.

## Technology Stack

-   **Python**
-   **Pandas** --- loading and working with tabular data
-   **Matplotlib** --- plotting the Elbow Method and customer segments
-   **Scikit-learn** --- clustering with K-Means and related
    preprocessing utilities, if used by the script

## Requirements

-   Python 3.9 or later recommended
-   `pip`

Install the Python libraries used by the project:

``` bash
pip install pandas matplotlib scikit-learn
```

If `main.py` imports any additional third-party packages, install those
packages too.

## How to Run

1.  Clone or download this repository.

2.  Open a terminal in the project folder.

3.  Install the required packages using the command above.

4.  Make sure `customer_data.csv` is in the same folder as `main.py`.

5.  Run the script:

    ``` bash
    python main.py
    ```

6.  Check the `CustomerSegmentation_Output/` folder for the generated
    results.

  -----------------------------------------------------------------------

  ----------------------------------- -----------------------------------

The output files are generated by the project script. Their exact

## Method Overview

1.  **Load data:** Read customer records from `customer_data.csv`.
2.  **Prepare data:** Select relevant features and prepare them for
    clustering as implemented in the script.
3.  **Choose cluster count:** Review the Elbow Method plot to help
    determine a suitable number of clusters.
4.  **Cluster customers:** Apply K-Means to group customers with similar
    feature patterns.
5.  **Review results:** Inspect the cluster visualization and exported
    CSV files.

## Notes

-   This is an exploratory customer-segmentation project. Cluster labels
    identify groups; they do not automatically represent fixed customer
    types or business outcomes.
-   Interpret each segment using the features and summary statistics in
    the dataset.
-   Results depend on the input data, selected features, preprocessing,
    and number of clusters.
-   Do not include private or personally identifiable customer
    information in a public repository.
